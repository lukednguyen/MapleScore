# MapleScore store listing

## Name
MapleScore

## Short description (Chrome summary, max 132 chars; AMO summary)
Adds an NCLC column to your TCF Canada results so you see your Canadian Language Benchmark level for each skill.

## Long description
MapleScore adds an NCLC (Niveaux de compétence linguistique canadiens) column to the results table on the official TCF Canada candidate site, tcfcandidat.france-education-international.fr.

Each score is converted to its NCLC level using the official TCF Canada equivalence table. Set your target NCLC level in the toolbar popup, and MapleScore shows which skills reach it.

Runs only on the TCF Canada candidate site. Collects no data. No account, no tracking, no remote code.

## Category
Chrome: Productivity > Education (suggested)
Firefox: Other (suggested)

## Single purpose (Chrome)
Show the NCLC equivalent of TCF Canada scores on the official TCF Canada results page.

## Permission justifications
storage: Saves the target NCLC level you choose so it persists between visits.
Host permission (https://tcfcandidat.france-education-international.fr/*): Reads the TCF Canada results table on this site to add the NCLC column. No other site is accessed.
Remote code: No. All code ships in the package.

## Privacy
MapleScore collects no data. Nothing is sent anywhere. The only stored value is your target NCLC level, kept in browser storage.
Chrome data usage form: tick no data types; certify all three disclosures.
Firefox: data collection declared as "none" in the manifest.
AMO source code: not required, because the package is unminified, unbundled source.
