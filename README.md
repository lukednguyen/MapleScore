# MapleScore

Firefox extension that adds an NCLC column to TCF Canada results.

## Purpose

Shows your NCLC level next to each CECRL result.
Celebrates with confetti when you reach your target.

## Setup

Requires Firefox.

```bash
git clone https://github.com/lukednguyen/MapleScore.git
```

## Run

1. Open `about:debugging#/runtime/this-firefox`.
2. Click "Load Temporary Add-on" and pick `manifest.json`.
3. Click the MapleScore icon and press Allow.
4. Pick your target NCLC (saved automatically).
